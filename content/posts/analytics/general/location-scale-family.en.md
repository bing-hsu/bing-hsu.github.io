> A distribution family means under-specified distributions that share the the
> same algebraic form. So the trick to graph a family is to understand:
>
> - this shared algebraic form
> - what are changeable - the family parameters

> Remember "Exponential Family"? They sit at the exact same conceptual tier.
> Both are **meta-classes of probability distributions** based on shared
> mathematical behavior.
>
> **The two families are neither subsets of each other nor mutually exclusive.
> They _intersect_, each contains distributions that the other does not have.**

A **location-scale family** is a collection of probability distributions formed
by taking a single, parameter-free "standard" distribution and applying an
affine (translate + scale) transformation to it.

> Location-scale Family:
>
> - a reference distribution form $P_0$
> - shift parameter $\mu$
> - scale parameter $\sigma$

Let $Z$ be a _"standardized"_ RV governed by a reference distribution with CDF
$F_0(z)$ and PDF $f_0(z)$.

A continuous RV $X$ belongs to the **location-scale family _headed_ by $Z$** if:

$$X = \mu + \sigma Z$$

- $\mu \in \mathbb{R}$ is the **location parameter** (governing _horizontal_
  translation).
- $\sigma > 0$ is the **scale parameter** (governing _horizontal_ stretching).

Conversely, any member $X$ of the family can be standardized back to the base:

$$Z = \frac{X - \mu}{\sigma}$$

**1st Moment: Expected Value**

$$E[X] = \mu + \sigma E[Z]$$

**2st Moment: Variance**

$$\text{SD}(X) = \sigma \cot \text{SD}(Z)$$

$$\text{Var}(X) = \sigma^2 \cot \text{Var}(Z)$$

**3rd / 4th Moments: Shape Invariance**

Skewness and Kurtosis are invariant to affine transformations:

$$\text{Skewness}(X) = \text{Skewness}(Z)$$

$$\text{Kurtosis}(X) = \text{Kurtosis}(Z)$$

## Prominent Members

Several widely used continuous distributions are location-scale families
generated by a standard base distribution:

**Normal Distribution:**

$$Z \sim \mathcal{N}(\mu = 0, \sigma = 1)$$

$$X = \mu + \sigma Z \sim \mathcal{N}(\mu, \sigma^2)$$

- $\mu$: mean
- $\sigma$: standard deviation ($\operatorname{Var}(X) = \sigma^2$).

**Logistic Distribution:**

$$Z \sim \operatorname{Logistic}(\mu = 0, \sigma = 1)$$

$$X = \mu + \sigma Z \sim \operatorname{Logistic}(\mu, \sigma)$$

- $\mu$: location parameter (mean and median)
- $\sigma$: scale parameter
  ($\operatorname{Var}(X) = \frac{\sigma^2 \pi^2}{3}$).

**Extreme Value (Gumbel for Minima):**

$$Z \sim \operatorname{Gumbel}(\mu = 0, \sigma = 1)$$

$$X = \mu + \sigma Z \sim \operatorname{Gumbel}(\mu, \sigma)$$

- $\mu$: location parameter (mode)
- $\sigma$: scale parameter
  ($\operatorname{Var}(X) = \frac{\sigma^2 \pi^2}{6}$).

**Uniform Distribution:**

$$Z \sim \operatorname{Uniform}(0, 1)$$

$$X = \mu + \sigma Z \sim \operatorname{Uniform}(\mu, \mu + \sigma)$$

- $\mu$: location parameter (lower bound $a$)
- $\sigma$: scale parameter (interval width $b - a$, where
  $\operatorname{Var}(X) = \frac{\sigma^2}{12}$).

**Student's $t$-Distribution (fdegrees of freedom $\nu$):**

$$Z \sim t_\nu(\mu = 0, \sigma = 1)$$

$$X = \mu + \sigma Z \sim t_\nu(\mu, \sigma)$$

- $\mu$: location parameter (mean when $\nu > 1$; median and mode)
- $\sigma$: scale parameter
  ($\operatorname{Var}(X) = \frac{\nu}{\nu - 2}\sigma^2$ when $\nu > 2$).

## Why Isolate $\sigma$ Instead of Absorbing it into $\epsilon$?

> This question touches the intricacy of model construction, not only about
> survival analysis, but about statistical modeling in general.

The answer: **The _error term_ $u$ can absorb $\sigma$, but not the
$\epsilon$.**

You can write the formula either in:

$$Y =\mu+\boldsymbol{\beta}^{\top}\mathbf{x}+\sigma\epsilon$$

or:

$$Y =\mu+\boldsymbol{\beta}^{\top}\mathbf{x}+u, \qquad u=\sigma\epsilon$$

There is a subtle difference in meaning between $u$ and $\epsilon$.

- $u$ is what we call the "random error"
- $\epsilon$ is the _"standard"_ random error

But, more profoundly, the nature of "randomness" about random variable $Y$ is
solely captured in $\epsilon$, as $\epsilon$ represents a explicit
choice/assumption of _**reference distribution**_. Each time we say "assume a
distribution to model $Y$", $\epsilon$ is the mathematical manifestation of that
line.

Define a **link function (linear predictor)**:

$$\eta(\mathbf{x})=\mu + \boldsymbol{\beta}^{\top}\mathbf{x}$$

encapsulating:

- the baseline level $\mu$, where $Y$ is when $\mathbf{x} = 0$
- the collective effect of covariates $\boldsymbol{\beta}^{\top}\mathbf{x}$
  - marginal effect of each covariate (feature):
    $\beta_i \in \boldsymbol{\beta}$
  - covariate $x_i \in \mathbf{x}$

The standard error term $\epsilon$ follows a reference distribution $P_0$

$$\epsilon = \frac{Y - \eta(\mathbf{x})}{\sigma} \sim P_0 $$

A random variable $Y$ is modeled by a distribution $P_Y$

- assuming a **_reference distribution_ $\epsilon \sim P_0$**
- modified by a _**location parameter**_ $\eta(\mathbf{x})$ and a _**scale
  parameter**_ $\sigma$

$$Y = \eta(\mathbf{x}) + \sigma \epsilon \sim P_Y $$

$$E[Y]=\eta(\mathbf{x})+\sigma E[\epsilon], \quad \operatorname{SD}(Y)=\sigma \cdot \operatorname{SD}(\epsilon), \quad \operatorname{Var}(Y) = \sigma^2 \cdot \operatorname{Var}(\epsilon)$$

> What Is a "Reference Distribution"?
>
> A reference distribution is a fully specified distribution that possesses the
> generalization power to describe many real-world processes.
>
> - Fully specified: no unknown parameters to estimate. Its CDF $F_0(z)$ and PDF
>   $f_0(z)$ contain only constants like $e$ and $\pi$.
> - The Geometric Template: It defines the invariant "shape" of the
>   distribution—its symmetry, tail weight, and kurtosis.

For example, in a simple linear model, random variable $Y$ is modeled using
observations $\mathbf{x}$:

$$Y = \eta(\mathbf{x}) + \sigma \epsilon$$

Assume a normal distribution $N(0,1)$:

$$\underbrace{\epsilon\sim N(0,1)}_{\text{reference distribution}} \quad\Longrightarrow\quad \underbrace{\sigma\epsilon\sim N(0,\sigma^2)}_{\text{scale}} \quad\Longrightarrow\quad \underbrace{\eta(\mathbf{x})+\sigma\epsilon \sim N\left(\eta(\mathbf{x}),\sigma^2\right)}_{\text{shift}}.$$

Therefore:

$$Y \sim N\left(\eta(\mathbf{x}),\sigma^2\right)$$

$$E[\epsilon] = 0 \implies E[Y] = \eta(\mathbf{x}) \quad \operatorname{Var}(\epsilon) = 1 \implies \operatorname{Var}(Y)=\sigma^2$$
